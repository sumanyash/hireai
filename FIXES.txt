HireAI — Bug Fixes & Improvements
===================================
Date: 2026-05-28
Server: hire.clouddialer.in


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. CRITICAL — ElevenLabs Webhooks Always Returning 401
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File: .env
Fix:  Added missing INTERVIEW_WEBHOOK_SECRET and EXPORT_TOKEN_SECRET
      constants. INTERVIEW_WEBHOOK_SECRET was not set, causing
      verify_hmac_signature() to reject every ElevenLabs webhook
      with 401. This was the root cause of 15 candidates stuck on_hold.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. CRITICAL — nginx Pointing at Wrong PHP-FPM Socket
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File: /etc/nginx/sites-available/hire.clouddialer.in
Fix:  Active nginx config was using php8.2-fpm.sock in PHPMyAdmin
      block but php8.3-fpm.sock for main app (which doesn't exist
      on this server). Standardised all fastcgi_pass directives to
      php8.2-fpm.sock. Site had been returning 502 due to this.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File: api/score.php
Fix:  Any unauthenticated user could trigger AI scoring by hitting
      GET /api/score.php?candidate_id=X&campaign_id=Y.
      Added verify_jwt() check for HTTP access. CLI path (cron/exec)
      still bypasses auth as required.
